## 왜 AI에게 직접 물으면 안 되는가?

당연히 Claude에게 직접 물을 수 있다. "핀둬둬가 살 만한지 분석해줘"라고. 그러면 "한편으로는… 다른 한편으로는…" 식의 균형 잡힌 분석을 받고, 마지막은 "투자에는 위험이 따르니 스스로 판단하세요"로 끝난다.

**이런 분석은 맞아 보이지만 의사결정에 쓸 수가 없다.**

AI Berkshire 가 해결하는 것은 "분석할 수 있느냐"의 문제가 아니라 **분석 품질과 의사결정 규율**의 문제다. 핵심 차이는 다음과 같다.

### 1. 결론을 강제한다, 어물쩍 넘어가지 않는다

AI에게 직접 물으면 양쪽 비위를 맞추는 "분석"을 받는다. AI Berkshire 는 다음을 강제로 출력한다: **통과/불통과/회색지대**, 구체적인 가격 구간과 차등 제안을 곁들여서.

> 일반 AI 답변: *"핀둬둬는 성장 잠재력이 있지만 경쟁 압력에도 직면해 있어 투자자는 저울질이 필요합니다…"*
>
> AI Berkshire 출력:

> | 전략 | 제안 | 가격 구간 |
> |------|------|---------|
> | 공격형 | 현재 가격대에서 20% 포지션 구축 가능 | $95-105 |
> | 안정형 | 자사주 매입 정책이 명확해진 뒤 포지션 구축 | $85-95 |
> | 보수형 | 10년 확실성 기준 미충족, 관망 | — |
>
> **거울 테스트**: 다섯 문장으로 설명을 끝내지 못하면 = 매수 안 함, 예외 없음.

### 2. 단일 분석이 아니라 네 대가 시각의 대립

"버핏 방법으로 분석 한번 해줘" 같은 단순한 게 아니다. 네 가지 시각은 **진짜 모순과 긴장**을 만들어낸다——

핀둬둬를 예로 들면:
- **돤융핑**(비즈니스 모델): 좋은 사업, C2M 모델은 복제하기 어렵다 → 점수 3.7/5
- **버핏**(재무·밸류에이션): 현금 제외 PER이 겨우 6.3배, 현금인쇄기 → 점수 4.4/5
- **멍거**(역발상): 해자가 생각보다 얕다, 더우인이 3년 만에 GMV 4조 위안 달성 → 점수 3.5/5
- **리루**(장기 확실성): 경영진 문화에 잠재 위험, 10년 후 불확실 → 점수 2.0/5

**버핏은 "진짜 싸다"고 하고, 리루는 "불확실하면 안 산다"고 한다**——이런 충돌이야말로 투자 의사결정의 진짜 모습이다. 단일 프롬프트로는 이런 다시각 대립을 만들 수 없는데, 바로 이것이 맹점을 피하는 핵심이다.

### 3. 구조화된 반(反)편향 메커니즘

AI가 가장 위험한 건 틀린 답을 주는 게 아니라, **맞아 보이지만 따져보면 무너지는** 답을 주는 것이다. AI Berkshire 는 프로세스 안에 여러 겹의 "속지 않기" 메커니즘을 내장했다.

| 메커니즘 | 무엇을 해결하나 | 예시 |
|------|------------|------|
| **정보 풍부도 등급(A/B/C)** | "자료가 많다 = 확실성이 높다"는 착각 방지 | 팝마트는 B등급: 데이터가 제한적이라 추산 지표에 신뢰도 표기 |
| **멍거식 역발상 검증** | 실패 시나리오를 강제로 사고 | "어떤 상황에서 핀둬둬가 망할까?" → 5대 시나리오와 확률 나열 |
| **빠른 부결 체크리스트** | 8개 레드라인 한 표 부결 | 경영진 정직성 오점 → 밸류에이션이 아무리 싸도 즉시 부결 |
| **반(反)컨센서스 점검** | 시장과 똑같은 생각을 피함 | "똑똑한 사람들은 왜 공매도하고 있나?" → 간과된 위험 발견 |
| **여백 원칙** | 차라리 "모른다"고 말함 | 데이터 부족 시 "회색지대"로 표기, 추측으로 확실성을 위장하지 않음 |

### 4. 금융 데이터의 정확성

LLM의 암산은 믿을 수 없다. PER에서 소수점 하나를 잘못 계산하거나, 시가총액 단위를 홍콩달러와 위안으로 혼동하면 잘못된 투자 결정으로 이어질 수 있다.

**실제 사례**: 텐센트를 분석할 때 출처별로 시가총액 데이터에 "홍콩달러 억"과 "위안 억" 두 단위가 섞여 있었다. AI Berkshire 의 처리 방식:

```bash
# 시가총액 수동 검증: 주가 × 총발행주식수, 보고된 데이터와 대조
python3 tools/financial_rigor.py verify-market-cap \
  --price 510 --shares 9.11e9 --reported 4.65e12 --currency HKD
# ✅ 검증 통과, 편차 0.08%에 불과
```

모든 계산은 Python `decimal.Decimal`(정확한 십진수)을 사용하고 `float`는 쓰지 않는다. 핵심 데이터는 최소 2개의 독립 출처로 교차 검증한다.

### 5. 재현 가능한 연구 프로세스

AI에게 직접 물으면 매번 출력의 형식·깊이·커버리지가 달라진다——오늘은 텐센트 분석에 해자 점수가 있다가, 내일은 메이투안 분석에서 그걸 잊어버릴 수 있다.

AI Berkshire 가 보장하는 것: **같은 입력 → 구조가 일관되고 깊이가 일관된 출력**. 이것이 의미하는 바는:
- 7개 기업을 가로로 비교, 점수 기준이 완전히 일치
- 같은 기업을 반년 뒤 다시 분석, 변화를 바로 대조
- 팀원 간 연구 결과를 정렬 가능

### 6. 멀티 에이전트 병렬 = 연구 깊이의 배가

`/investment-team` 은 4개의 독립 Agent를 **동시에** 가동해 한 기업을 연구한다. 각 Agent가 각자 웹을 검색하고, 데이터를 교차 검증하며, 독립적으로 결론을 낸다. 이것은 하나의 프롬프트를 네 조각으로 쪼갠 게 아니라——4명의 "애널리스트"가 각자 완전한 연구를 한 뒤 Team Lead가 종합하는 것이다.

한 사람이 AI에게 직접 물으면 컨텍스트 윈도우는 하나다. 4개 Agent 병렬은 곧 4배의 검색량, 4배의 정보원, 4개의 독립 시각이다.

```
┌─────────────────────────────────────────────┐
│              Team Lead (당신)                │
│         총괄 조정 · 종합 판단                │
├──────┬──────┬──────────┬───────────┤
│ Agent 1    │ Agent 2    │ Agent 3        │ Agent 4         │
│ 비즈니스 모델 │ 재무·밸류에이션 │ 산업 경쟁      │ 위험·경영진      │
│ 돤융핑 시각 │ 버핏 시각  │ 멍거 시각      │ 리루 시각        │
└──────┴──────┴──────────┴───────────┘
        ↓ 병렬 연구, 실시간 진행 보고 ↓
              최종 종합 보고서
```

### 한 문장 요약

> **보통 사람이 AI에게 물어서 얻는 건 "맞아 보이는 분석"이고, AI Berkshire 로 얻는 건 "의사결정에 쓸 수 있는 투자 연구 보고서"다.**

### 1. `/investment-research` — 네 대가 종합 분석

가장 포괄적인 단일 기업 심층 연구 프레임워크. 일곱 개 모듈을 순서대로 실행한다:

```
데이터 수집 → 사업의 본질(돤융핑) → 해자(버핏) → 역발상(멍거)
    → 경영진 평가(돤융핑+버핏) → 문명 트렌드(리루) → 밸류에이션과 안전마진
```

**핵심 특징**:
- AI 연구 편향 자각 메커니즘(A/B/C급 정보 풍부도 등급)
- 핵심 데이터 다중 출처 교차 검증(시가총액 수동 검증, 최소 2개 독립 출처)
- 네 대가의 "추궁"이 전문을 관통
- 3시나리오 밸류에이션(낙관/중립/비관) + 역방향 DCF

**출력 예시 발췌**:

> #### 종합 의사결정 메모
>
> | 차원 | 결론 | 확신도 |
> |------|------|--------|
> | 사업 품질(돤융핑) | 매우 우수: 플랫폼형 사업, 양면 네트워크 효과, 한계비용 제로 수렴 | ★★★★★ |
> | 해자(버핏) | 넓고 더 넓어지는 중: 네트워크 효과+전환비용+규모의 경제 삼중 중첩 | ★★★★☆ |
> | 경영진(돤융핑+버핏) | 우수: 창업자가 키를 잡고, 자본배분 규율이 강함 | ★★★★☆ |
> | 최대 위험(멍거) | 규제 정책 불확실성, 신규 사업 적자가 전체 이익을 끌어내림 | ★★★☆☆ |
> | 문명 트렌드(리루) | 디지털 소비 트렌드에 부합하나 "문명급 패러다임 전환"은 아님 | ★★★★☆ |
> | 밸류에이션(버핏+돤융핑) | 현재 PER 18배, 역사적 중앙값 대비 낮은 편, 일정한 안전마진 존재 | ★★★★☆ |
>
> **돤융핑**: "이 사업의 본질은 소비자와 상인을 연결하고, 효율 향상의 돈을 버는 것이다. 좋은 사업의 표지는: 사용자가 많을수록 상인이 많고, 상인이 많을수록 사용자가 많은 것. 플라이휠이 일단 돌기 시작하면 멈추기 어렵다."
>
> **멍거**: "거꾸로 생각해보라——이 회사가 내일 사라진다면 사용자와 상인은 어떻게 할까? 답이 '금방 대체품을 찾는다'라면 해자는 충분히 깊지 않다. 답이 '생활이 매우 불편해진다'라면 주목할 가치가 있다."

    ↓ 통과
제5관: 안전마진 (가격이 싼가?)
    ↓ 통과
제6관: 의사결정 규율 (이성인가 아니면 FOMO인가?)

### 5. `/industry-funnel` — 산업 깔때기(퍼널) 선별

하나의 산업/방향에서 출발해 **전체 시장 → ≤10곳 → 3곳**으로 단계별 정밀 선별한다:

```
전체 시장 스캔(활성도 + 상승폭 + 시총 상위 30 합집합, 30-60곳)
    ↓ 가치투자 5개 하드 지표
1차 선별 ≤ 10곳
    ↓ 정밀 분석(각 300-500자)
정밀 분석 ≤ 10곳
    ↓ 최종 선정(포트폴리오 상호보완성 기준, 점수 상위 3이 아님)
네 대가 심층 분석 3곳(각 800-1200자)
    ↓
추천 포트폴리오(코어 / 위성 / 옵션) + 매매 신호
```

**핵심 특징**:
- 각 단계마다 명확한 잔류/탈락 기준, 탈락한 종목은 탈락 이유를 남김(블랙박스가 아님)
- 최종 3곳은 "포트폴리오 상호보완성" 기준으로 선정(고확실성 + 중간 탄력성 + 고탄력성), 점수 상위 3 순위가 아님
- "미래 IPO 후보"를 강제로 나열해 1차 시장 핵심 플레이어 누락 방지
- AI 편향 자각 메커니즘: 선두주 선호 / 영어 선호 / 스토리 선호 / 상장사 선호에 대응

**`/industry-research` 와의 차이**:
- `industry-research` 는 산업체인 구조와 전경에 무게(단계별 슬라이스)
- `industry-funnel` 은 개별주 선별 깔때기에 무게(전체 시장에서 단계별로 3곳까지 정밀 선별)

**실측: AI 산업 4개 세부 트랙 병렬(2026-05-09)**:

| 세부 트랙 | 최종 3곳 | 코어 비중 추천 |
|-------|---------|------------|
| AI 연산력 | TSMC / NVIDIA / SK Hynix | TSMC ★★★★★ |
| AI 모델 | Alphabet / Meta / 알리바바 | Alphabet ★★★★★ |
| AI 응용 | 마이크로소프트 / Adobe / AppLovin | 마이크로소프트 + Adobe ★★★★ |
| AI 인프라 전력 | Eaton / 터볜전공 / Talen Energy | Eaton + 터볜전공 ★★★★ |

**핵심 발견**: AI 응용 계층의 최대 승자는 AI Native 기업이 아니라 채널+데이터+워크플로 내재도를 갖춘 성숙한 거대 기업이다——이는 1995-2000년 인터넷 버블의 "곡괭이 장사(picks and shovels)" 역사적 법칙과 호응한다(아마존과 애플이 이기고 Pets.com이 진다).

정보가 희소한 비상장사를 위해 설계된 "탐정식" 연구 프레임워크:

**핵심 차별화**:
- **재무 데이터 짜맞추기**: 투자설명서, 모회사 실적, 펀딩 뉴스, 산업 데이터 등 다중 출처에서 짜맞춤
- **신뢰도 표기**: 각 데이터 포인트에 🟢높음 / 🟡중간 / 🔴낮음 신뢰도 표기
- **다중 방법 밸류에이션 교차**: 펀딩 밸류에이션법 + 비교기업법 + DCF + 종국 역산법
- **엑시트 경로 분석**: IPO/M&A/2차 양도 전 경로 평가

**출력 예시 발췌**:

> #### 기업 프로필 속람: SpaceX
>
> | 항목 | 내용 |
> |------|------|
> | 최신 밸류에이션 | ~$350B (2025년 2차 시장) 🟡 |
> | 추산 매출 | ~130억 달러 (2024년) 🟡 |
> | Starlink 사용자 | 400만+ (2024년 말) 🟢 |
> | 발사 횟수 | 100+ 회/년 (2024년) 🟢 |
>
> #### 밸류에이션 판단
>
> | 방법 | 밸류에이션 구간 | 설명 |
> |------|---------|------|
> | 최근 펀딩 | $350B | 2차 시장 호가, 유동성 프리미엄 있음 |
> | 비교기업법 | $200-280B | 통신+항공우주+국방 벤치마크 |
> | DCF(중립) | $250-350B | Starlink 2027년 300억 달러 매출 가정 |
> | 종국 역산 | $400-600B | 스타링크가 글로벌 통신 인프라가 된다고 가정 |
>
> **종합 합리적 밸류에이션 구간: $250B - $400B**

### 7. `/news-pulse` — 주가 급변 뉴스 귀인

"주가 급등/급락 시 무슨 일이 일어났는지 빠르게 파악"하기 위해 설계된 인텔리전스 대응 Skill. **심층 투자 연구가 아니라 10-15분의 빠른 귀인**——포지션 급변 시 잡글에 따른 불안에 빠지거나 맹목적 손절에 빠지지 않게 한다.

**핵심 차별화**:
- **4차원 병렬 정찰**: 회사 이벤트 / 규제 정책 / 산업 경쟁자 / 시장 심리(셀사이드+인플루언서+남향 자금)
- **나열보다 귀인 우선**: 모든 뉴스를 한 번 나열하는 게 아니라 "어떤 이벤트가 이번 주가 급변에 걸맞은가"를 판단
- **성격 판단 강제**: 가치 이벤트 / 심리 변동 / **진짜 원인 불명** / 혼합——그중 "진짜 원인 불명"이 가장 가치 있는 출력(내부 선행 매매 존재 가능성)
- **명확한 행동 제안**: 심층 연구 트리거 여부, 논거 재검토 필요 여부, 관찰만 할지 여부 등

**다른 Skill 과의 차이**:
| 상황 | 무엇을 쓰나 |
|------|------|
| 완전한 투자 연구(시간 단위) | `/investment-team` 또는 `/investment-research` |
| 실적 심층 정독 | `/earnings-review` |
| 장기 논거 추적 | `/thesis-tracker` |
| **주가 급변 10분 귀인** | **`/news-pulse`** |

**출력 예시 발췌**(텐센트 4/17-5/01 실측, 14일 -10.47%):

> #### 한 문장 귀인
> 이번 -10.47% 하락폭은 약 70-80%가 자금면+심리면 요인(자사주 매입 침묵기 + 남향 자금 감축 + 섹터 beta + AI 내러티브 탈취)에서 비롯됐고, 20-30%가 AI 투자 2배 증액의 이연 소화에서 비롯됐다——**펀더멘털에 악재 없음**, 셀사이드는 매수 컨센서스 유지, 성격상 "유동성+심리형 조정"에 해당하며 가치 이벤트가 아니다.
>
> #### 급변 귀인표
>
> | 후보 설명 | 추정 기여 | 신뢰도 |
> |---------|--------|--------|
> | 자사주 매입 침묵기 소멸(구조적, 5/13 실적 발표 전) | -3% ~ -4% | 높음 |
> | 남향 자금이 텐센트 순매도로 전환 | -2% ~ -3% | 높음 |
> | AI 내러티브를 경쟁 제품에 빼앗김(DeepSeek V4/Qwen3.6/문샷 1T) | -1% ~ -2% | 중간 |
> | 섹터/매크로 beta(유가+지정학+Fed Warsh 매파) | -2% ~ -3% | 높음 |
> | 1분기 보고서 전 위험 회피 | -1% ~ -2% | 중간 |
> | 펀더멘털 악화 | **0%** | 매우 높음(배제) |
>
> #### 성격 판단: ✅ 혼합형
> 70% 자금면/심리면 + 20% AI 장기 내러티브 우려 + 10% 1분기 보고서 전 불확실성
>
> **핵심 반증**: 돤융핑 4/8 텐센트 풋 매도(강세 베팅); 셀사이드 24개사 컨센서스 Strong Buy; 넷이즈 4/30 역행 상승 2%(게임 업종 문제 배제); 텐센트가 항셍테크를 7%p 언더퍼폼(항셍테크는 월간 오히려 4% 상승).

호출 방식:

```
/news-pulse 텐센트
/news-pulse 핀둬둬 12% 하락 1주일 내
/news-pulse 미호요(miHoYo)
```

## 설계 이념

### 네 대가 방법론 융합

```
              ┌──────────────────┐
              │    돤융핑         │
              │  "맞는 사업"      │
              │  비즈니스 모델 본질 │
              └────────┬─────────┘
                       │
    ┌──────────────────┼──────────────────┐
    │                  │                  │
    ▼                  ▼                  ▼
┌────────┐     ┌──────────┐      ┌────────┐
│ 버핏    │     │   멍거    │      │  리루   │
│ 해자    │     │ 역발상    │      │ 문명 트렌드│
│ 안전마진│     │ 위험 체크리스트│   │ 패러다임 전환│
│ 경영진  │     │ 편향 자가점검│    │ 산업 가치│
└────────┘     └──────────┘      └────────┘
```

네 대가는 단순한 분업이 아니라 **서로 도전하도록** 설계되었다:
- 돤융핑이 "좋은 사업"이라고 하면, 멍거는 "어떻게 망할 수 있나"를 묻는다
- 버핏이 "충분히 싸다"고 하면, 리루는 "10년 후에도 존재하는가"를 묻는다
- 당신이 얻는 건 네 개 보고서의 짜깁기가 아니라 네 가지 사고방식의 충돌이다

### 금융 엄밀성 도구 (`tools/financial_rigor.py`)

| 기능 | 명령 | 해결하는 문제 |
|------|------|-----------|
| **시가총액 검산** | `verify-market-cap` | 주가×총발행주식수 정확 계산, 단위 오류 탐지 |
| **밸류에이션 검산** | `verify-valuation` | PE/PB/ROE/FCF Yield 정확 십진수 계산 |
| **다중 출처 교차 검증** | `cross-validate` | N개 출처의 동일 데이터 자동 대조, 허용오차 초과 시 경보 |
| **3시나리오 밸류에이션** | `three-scenario` | 낙관/중립/비관 목표가 정확 계산 |
| **벤포드 법칙 탐지** | `benford` | 재무 데이터 첫째 자리 숫자 분포 이상 탐지 |
| **정확 계산기** | `calc` | 임의의 재무 표현식 정확 계산, LLM 암산 대체 |

**설계 원칙**: 모든 계산은 Python `decimal.Decimal`(정확한 십진수)을 사용하고 `float`(부동소수점 근사)를 쓰지 않는다. `0.1 + 0.2 = 0.3` 은 금융 상황에서 실패해서는 안 된다.
