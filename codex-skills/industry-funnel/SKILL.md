1. 중요한 종목을 하나도 빠뜨리지 않기(중국 A주, 홍콩주, 미국주, 비상장 후보 포함)

3. 진짜 깊이 연구할 가치가 있는 상위 3개에 집중하기
4. 각 단계마다 명확한 잔류/탈락 기준을 두어 복기 가능하고 추적 가능하게 하기

`industry-research`와의 차이:
- `industry-research`는 산업체인 구조와 전체 조망에 무게를 두며, 단계(환절)별로 절개한다

## 1단계: 전체 시장 스캔 진입

### 1.1 활성 종목 정의(3개 분류의 합집합)

**A류 - 거래 활성도**:
- 최근 30일 일평균 거래대금이 산업 내 상위권(중국 A주/홍콩주/미국주 각각 상위 30 추출)

**B류 - 상승률 순위**:
- 최근 30일 상승률 상위 20
- 최근 90일 상승률 상위 20
- 양자의 합집합

**C류 - 시총 기준**:
- 산업 내 시총 상위 30(등락 무관)

최종 스캔 풀 = A ∪ B ∪ C, 예상 30-60개.

### 1.2 반드시 검색해야 할 시장

| 시장 | 출처 제안 |
|------|---------|
| 중국 A주(상하이·선전) | 통화순(同花順)/둥팡차이푸(東方財富) 산업 섹터, 통다신(通達信) |
| 홍콩주 | 푸투(富途)/통화순 홍콩주, HKEX 산업 분류 |
| 미국주 | NASDAQ/NYSE 산업 ETF 편입 종목, Yahoo Finance |
| 한국 시장 | KOSPI/KOSDAQ 종목은 `tools/krx_data.py`(quote/valuation/financials/search)로 조회하고 통화는 원(KRW) 기준 |
| 국제 시장 | 일본·한국·대만·유럽의 관련 회사를 빠뜨려서는 안 됨(특히 반도체, 전자) |
| 비상장 회사 | "향후 IPO 후보" 별도 섹션으로 정리하고, 최신 밸류에이션과 잠재적 IPO 시점 명시 |

### 1.3 출력 형식

| 회사명 | 코드 | 시장 | 시총 | 주력 사업 한 줄 | 해당 산업 비중 | 선정 분류(A/B/C) |
|-------|------|-----|------|----------|-----------|----------------|

**핵심 자체 점검**:
- 산업 비중 < 30%인 "끼어든 종목"은 신중히 다루고 "순수 종목 아님"으로 표기
- 중국/아시아 시장을 영문 자료가 적다는 이유로 빠뜨리지 말 것
- 소형주를 AI의 대장주 선호 때문에 빠뜨리지 말 것

## 2단계: 가치투자 5개 하드 지표 1차 선별 → ≤ 10개

1단계의 30-60개 회사에 대해 회사별로 5개 하드 지표를 적용한다.

### 2.1 5개 하드 지표

| # | 지표 | 통과 기준 | 완화 조건 | 데이터 출처 |
|---|------|---------|---------|---------|
| 1 | PE 밸류에이션 | 합리적(과거 구간·동종업계 대비) | 고성장은 PEG < 1.5까지 완화 가능 | 실적 + wind/통화순 |
| 2 | ROE | > 15% 또는 최근 3년 추세 개선 | 자산집약 산업은 완화 가능 | 실적 |
| 3 | 영업현금흐름 | 양(+)이며 순이익 대비 > 70% | — | 실적 |
| 4 | 부채비율 | < 60% | 공공유틸리티/전력은 70%까지 완화 | 실적 |
| 5 | 해자 신속 평가 | ★★★ 이상 | — | 정성적 판단 |

**해자 5가지 유형**:
- 브랜드/가격결정력
- 전환비용/사용자 충성도
- 네트워크 효과
- 규모의 경제
- 기술/라이선스/자원 장벽

### 2.2 출력 형식

| 회사 | PE | ROE | 현금흐름/순이익 | 부채비율 | 해자 | 종합 | 잔류/탈락 | 탈락 사유 |
|------|----|----|-----------|-------|-------|------|------|---------|

**잔류 규칙**:
- 5개 항목 전부 합격 → 즉시 잔류
- 4개 합격 + 1개 근접 → 잔류하되 황색 표기
- 4개 미만 → 탈락, 사유 명시

**목표**: ≤ 10개 잔류. 너무 많이 잔류하면(> 12) 해자 기준을 ★★★★로 올려 한 번 더 선별한다.

### 3.2 최종 3개 선정 기준

점수 순위로 상위 3개를 고르는 것이 아니라, "포트폴리오 상호 보완성"으로 선정한다:
- 최소 1개 "고확실성·저탄력성"(버핏형)
- 최소 1개 "중간 확실성·중간 탄력성"(성장형)
- 선택적으로 1개 "고탄력성·고리스크"(옵션형)

특정 하위 트랙에서 충분히 좋은 회사 3개를 찾지 못한다면, 차라리 "최종 2개 + 관찰 1개"라고 쓰고 억지로 숫자를 채우지 않는다.

## 4단계: 4대 대가 심층 분석(3개, 회사별 800-1200자)

최종 선별된 3개 회사에 대해 4대 대가 시각 심층 분석을 수행한다.

### 4.1 돤융핑 시각: 사업의 본질

- 이 회사가 무슨 사업을 하는지 한 줄로 정의
- 이것이 좋은 사업인가? 왜?
- 이 회사의 "본분(本分)"은 무엇인가? 경영진이 거기서 벗어나지 않았는가?
- 비즈니스 모델의 "지속성"은 어디에 있는가?

### 4.2 버핏 시각: 해자의 깊이

- 5가지 해자로 점수 매기기(★1-5), 구체적 증거 나열
- 10년 후에도 해자가 남아 있을까?
- 지금 매수하는 "안전마진"은 어디에 있는가?

| 해자 | 강도 | 구체적 증거 |
|-------|------|---------|
| 브랜드/가격결정력 | | |
| 전환비용 | | |
| 네트워크 효과 | | |
| 규모의 경제 | | |
| 기술/라이선스 장벽 | | |

### 4.3 멍거 시각: 리스크와 실패 모드

- 이 회사가 가장 가능성 높게 실패하는 방식은?(실패 경로 상위 3개 나열)
- 최악의 시나리오에서 얼마의 가치인가?(극도로 간소한 밸류에이션)
- 똑똑한 사람들은 왜 사지 않는가?(역방향 논증)
- 도덕적/규제/경영진 리스크가 있는가?

### 4.4 리루 시각: 문명급 트렌드 포지셔닝

- 이 회사가 속한 트랙은 "문명급 패러다임 전환"인가, 아니면 "일시적 열풍"인가?
- 역사상 가장 가까운 기술 혁명 유추는?
- 10-20년 후 이 회사의 종국(終局)은?
- 승자독식 구도인가?

### 4.5 종합 추천도

```
추천도: ★★★★☆
포지션 유형: 핵심 / 위성 / 옵션 / 관찰
권장 매수 구간: 현재가 / N% 조정 후 / 인내심 갖고 대기
권장 보유 비중: 해당 테마 포지션의 X%
핵심 모니터링 지표: (이 회사의 논리가 반전되는 신호는 무엇인가)
```

## AI 리서치 편향 자각(중요)

깔때기 선별 과정에서 AI가 빠지기 쉬운 함정:

| 편향 | 양상 | 대응 |
|------|-----|------|
| 대장주 선호 | 대형주는 자료가 많고 분석 분량이 길어 "더 좋아" 보임 | 하드 지표와 해자 점수로 평가하고, 보고서 분량으로 순위를 매기지 말 것 |
| 영문 선호 | 미국주 자료가 풍부해 중국 A주·홍콩주가 저평가되기 쉬움 | 반드시 중·영문 모두 검색, A/H 회사를 빠뜨려서는 안 됨 |
| 스토리 선호 | 높은 상승률 + 미디어 열기 = 더 좋아 보이는 "AI 컨셉주" | "AI 매출 비중" vs "AI 스토리 비중"을 구분하고 실제 사업을 볼 것 |
| 현재 선호 | 현재 재무가 좋은 회사가 선정되기 쉬워, 전환기의 다크호스를 놓칠 수 있음 | 2층 1차 선별에서 "추세 개선"을 완화 조건으로 허용 |
| 상장 선호 | 상장사만 보면 트랙의 최고 플레이어를 놓칠 수 있음 | 반드시 "향후 IPO 후보"를 나열하고 밸류에이션과 시점 창을 표기 |

## 데이터 표본 점검(출시 승인 프로세스)

보고서 작성 후 데이터 표본 점검을 실행하고, 통과해야만 발행한다:

```bash
# Step 1 — 점검 목록 추출(15% 무작위 표본)
python3 ~/ai-berkshire/tools/report_audit.py extract \
  --report <보고서 파일 경로>

# Step 2 — 목록 각 항목을 신뢰 가능한 정보원에서 수치 취득(skills/financial-data.md 참조)

# Step 3 — 출시 승인/반려 판정 출력
python3 ~/ai-berkshire/tools/report_audit.py verdict \
  --results '<채워 넣은 JSON>' \
  --report <보고서 파일명>
```

**【출시 승인】** 전부 통과 → 보고서 발행 가능; **【반려】** 불통과 항목 존재 → 수정 후 재심사.
