# 공급망 병목 헌터: AI 기반 글로벌 산업체인 병목 차익거래

$ARGUMENTS 슈퍼 트렌드에 대해 공급망 병목 스캔 및 차익거래 기회 발굴을 수행한다.

## 핵심 이념

"AI가 어떤 종목을 추천하는가"를 묻지 말고, "이 트렌드가 계속 확장된다면 어느 고리가 먼저 부족해질까?"를 물어라.

전통적 투자 리서치는 1등주, 이미 알려진 트랙을 본다. 이 시스템은 거꾸로 간다: **물리적 공급망의 목줄 위치에서 출발해, 아무도 주목하지 않지만 일단 공급이 끊기면 업계 전체가 멈춰 서서 기다려야 하는 회사를 찾는다**.

초과수익의 원천: 1차 병목(GPU, HBM, 전력)은 이미 충분히 가격에 반영됐다. 진짜 alpha는 **2차, 3차 층**에 있다 — 광모듈, 레이저, InP 기판, SOI 웨이퍼, 에피택시 장비, 웨이퍼 레벨 테스트, IC 기판, 특수 유리섬유 등.

## 1단계: 슈퍼 트렌드 확인

### 1.1 트렌드 선별 기준

작은 바람몰이 속에서 환상을 찾지 않고, 다음 조건을 **전부** 충족하는 슈퍼 트렌드만 좇는다:

| 기준 | 요구사항 | 검증 방법 |
|------|------|---------|
| 지속성 | 최소 3-5년 확실한 성장 | 업계 전망, 자본적지출 계획 검색 |
| 물리성 | 실제 하드웨어/소재/장비 건설 필요 | "소프트웨어 업그레이드"와 "물리적 증설"을 구분 |
| 규모성 | 글로벌 자본적지출 > 연 500억 달러 | 선두 플레이어 capex 가이던스 검색 |
| 가속성 | 수요 증가율 > 공급 증설 속도 | 수요 증가율 vs 생산능력 확장 계획 비교 |

### 1.2 현재 추적 중인 슈퍼 트렌드 목록

매번 실행 시 업데이트, 초기 목록:

1. **AI 인프라 건설** — 데이터센터, GPU 클러스터, 네트워크 인터커넥트, 전력
2. **에너지 전환** — 원전 재가동, 전력망 업그레이드, 에너지저장(ESS)
3. **국방 현대화** — 서방 국방비 상승 사이클, 공급망 재편
4. **반도체 재산업화** — 미국·유럽·일본 보조금 공장 건설, 장비/소재 병목
5. **우주 경제** — 위성 인터넷, 발사 빈도 급증

사용자가 구체적 트렌드를 지정한 경우(예: "AI 인프라"), 해당 트렌드에만 집중한다.

### 1.3 트렌드 검증 출력

```
트렌드 이름:
핵심 동력: (한 문장)
이미 발생한 검증 이벤트(최소 3개):
  1. [날짜] [이벤트] [출처]
  2.
  3.
자본적지출 규모: 글로벌 약 $XX억/년, 증가율 YY%
수급 갭 판단: 수요 증가율 > 공급 증설 속도? 예/아니오/불확실
트렌드 확인: ✅ 추적 가능 / ❌ 증거 부족, 일단 추적 안 함
```

## 2단계: 공급망 물리적 분해

### 2.1 계층 분해 프레임워크

**개념 층에 머무르지 말고 물리적 실체까지 분해한다**.

```
Layer 0(말단): 최종 제품/서비스
    │
Layer 1(핵심 부품): 이미 시장의 충분한 관심을 받는 핵심 하드웨어
    │                 ⬆ 가격 충분히 반영, alpha 제한적
    │─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
    │                 ⬇ 관심도 낮음, alpha 집중 구간
    │
Layer 2(서브 부품/소재): 핵심 부품을 떠받치는 부품과 소재
    │
Layer 3(상류 장비/원료): 서브 부품 제조에 필요한 장비와 원자재
    │
Layer 4(인프라): 전력, 냉각, 토지, 인재, 인증
```

### 2.2 AI 인프라를 예로 든 분해 템플릿

```
Layer 0: AI 모델 학습/추론 서비스
Layer 1: GPU/가속기, HBM 메모리, 서버, 데이터센터
Layer 2(중점 스캔 구간):
  ├─ 네트워크 인터커넥트: 광모듈, 광섬유, 스위치 칩, 동축케이블
  ├─ 광통신 핵심: 레이저(EML/VCSEL/CW), 변조기, 광검출기
  ├─ 반도체 소재: InP 기판, GaAs 기판, SOI 웨이퍼, SiC 기판
  ├─ 첨단 패키징: CoWoS 기판, HBM TSV, ABF 기판 필름
  ├─ PCB/기판: 고주파 고속 PCB, IC 기판, 특수 유리섬유 직물
  ├─ 테스트: 웨이퍼 레벨 테스트(Probe Card), 번인 테스트, ATE
  ├─ 방열/냉각: 액냉 시스템, CDU, 침지식 냉각액
  └─ 전력 연결: 부스웨이, UPS, 배전반, 변압기
Layer 3:
  ├─ 에피택시 장비: MOCVD, MBE
  ├─ 노광/식각: 특수 파장 노광, InP 식각
  ├─ 원자재: 고순도 금속(인듐, 갈륨, 게르마늄), 특수가스, 타깃재
  └─ 인증/표준: MSA 표준, Telcordia 인증
Layer 4:
  ├─ 전력: 원전, 천연가스 발전, 송배전
  ├─ 냉각수/방열 인프라
  └─ 데이터센터 토지/인허가
```

## 3단계: 병목 식별 — "목줄" 찾기

### 3.1 병목 판정 6개 기준

Layer 2-3의 각 고리에 대해 항목별로 평가:

| # | 기준 | 질문 | 점수 |
|---|------|------|------|
| 1 | **공급 집중도** | 글로벌 공급사 ≤3개? | 🔴 ≤2개 / 🟡 3-5개 / 🟢 >5개 |
| 2 | **증설 주기** | 신규 생산능력 확보에 얼마나 걸리나? | 🔴 >2년 / 🟡 1-2년 / 🟢 <1년 |
| 3 | **대체 난이도** | 다른 기술/소재로 대체 가능한가? | 🔴 대체 불가 / 🟡 부분 대체 가능 / 🟢 쉽게 대체 |
| 4 | **가동률** | 현재 생산능력 가동률은? | 🔴 >90% / 🟡 70-90% / 🟢 <70% |
| 5 | **수요 증가율** | 전방 수요 증가율은? | 🔴 >50%/년 / 🟡 20-50% / 🟢 <20% |
| 6 | **고객 검증 주기** | 신규 공급사 진입에 얼마나 검증이 필요한가? | 🔴 >1년 / 🟡 6-12개월 / 🟢 <6개월 |

**병목 등급**:
- 🔴🔴🔴 ≥4개 → **S급 병목**(단일 장애점급, 최고 우선순위)
- 🔴🔴 3개 → **A급 병목**(심각하게 제약됨)
- 🔴 1-2개 → **B급 병목**(압박은 있으나 통제 가능)
- 🔴 없음 → 병목 아님, 건너뛰기

```
  1. [고리명] — [원인 한 문장] — 공급사: [회사 목록]
  2.

A급 병목(심각하게 제약):
  1.
  2.

  1.
  2.

최근 변화(직전 스캔 대비):
  - [신규/상향/하향/해소] [고리명] — [원인]
```

## 4단계: 회사 선별 — 병목에서 종목으로

### 4.1 각 S급 및 A급 병목에 대해 관련 상장사를 모두 찾는다

검색 방법:
- WebSearch "{병목 고리} supplier listed company"
- WebSearch "{병목 고리} manufacturer stock"
- WebSearch "{병목 제품} market share company"

### 4.2 1차 선별 기준(빠른 필터링)

| 기준 | 요구사항 | 이유 |
|------|------|------|
| 상장 여부 | 상장됨(중국 A주/홍콩/미국/일본/대만/유럽) | 거래 가능 |
| 병목 사업 비중 | 매출의 >30%가 병목 고리에서 발생 | 순도 |
| 시가총액 | <100억 달러 우선 | 대형주는 이미 충분히 가격에 반영됨 |
| 유동성 | 일평균 거래대금 >100만 달러 | 진입/청산 가능 |

한국(KOSPI/KOSDAQ) 종목은 `tools/krx_data.py`로 조회하며, 통화는 원(KRW) 기준이다.

### 4.2.1 밸류에이션 점검(반드시 수행, 건너뛸 수 없음)

**병목이 실재한다 ≠ 투자 기회.** 모든 회사에 대해 PS, PE를 계산하고 보고서에 명시해야 한다. 아래 조합 조건으로 밸류에이션이 과하게 선반영됐는지 판단한다:

#### 밸류에이션 적신호(어느 하나라도 충족 → 시그널 강도 상한 ★★, "⚠️ 밸류에이션 과반영" 표기)

1. **시가총액 > TAM의 20%**: 회사 시가총액이 도달 가능 시장 규모의 20%를 이미 초과 — 성장 기대가 과도하게 내재화됨
2. **PS > 30x 및 매출 증가율 < 100%**: 고밸류에이션이지만 증가율이 이를 떠받치기에 부족. 증가율 >100%인 회사는 PS 적신호에서 면제되나 여전히 "⚠️ 고밸류에이션은 고성장의 지속 검증 필요" 표기
3. **시가총액 > 5년 낙관적 매출 전망의 10배**: 가장 낙관적 가정이 전부 실현되더라도 현재 가격이 여전히 과도
4. **증자 후 60일 이내 주가 2배**: 심리 주도 특성 뚜렷, 시그널 강도 한 단계 하향

#### 밸류에이션 황신호(추가 설명 필요, 없으면 등급 하향)

1. **적자 + PS > 15x**: ★★★ 진입은 허용하되 수익 경로와 타임라인을 반드시 설명
2. **PS가 동종 흑자 기업의 5배 이상**: 프리미엄 원천(시장 점유율, 증가율 차이, 진입장벽 차이)을 반드시 설명
3. **PE > 80x**: PEG를 계산하고 증가율이 이를 떠받치는지 설명 필요

#### 밸류에이션 청신호(가점 항목)

- PS < 10x 및 매출 성장 중 → 시그널 강도 한 단계 가점
- PE < 30x 및 해자 보유 → "밸류에이션에 안전마진 존재" 표기

#### 밸류에이션 합리성 검증(필수)

각 종목에 대해 답한다: "현재 시가총액으로 매수하고, 가장 낙관적 시나리오가 전부 실현된다고 가정하며, 10년 후 25x PE로 청산한다면 연환산 수익률은 얼마인가?" 연환산 수익률 <10% → "현재 가격은 안전마진을 갖추지 못함" 표기.

**주의**: 밸류에이션 점검의 목적은 "PS 100배 적자 회사"를 추천하는 명백한 오류를 막는 것이지, 모든 고밸류에이션 초기 기업을 배제하는 것이 아니다. 핵심은 증가율, TAM, 경쟁 구도가 현재 밸류에이션을 떠받칠 수 있는지이며, 일률적 잣대가 아닌 구체적 분석이 필요하다.

### 4.3 심층 선별 차원

1차 선별을 통과한 회사에 대해 한 곳씩 평가:

```
## {회사명}({코드})

**병목 포지션**:
- 공급망 내 구체적 위치
- 시장 점유율: 글로벌 X위, 비중 XX%
- 고객 명단(알려진 것)

**생산능력과 확장**:
- 현재 생산능력 / 가동률
- 증설 계획 / 타임라인
- 증설 소요 자금 vs 보유 현금

**재무 스냅샷**:
- 시가총액 / 매출 / 이익 / 증가율
- 병목 사업 매출 비중
- 매출총이익률 추세(병목이 빡빡할수록 매출총이익률은 상승해야 함)

**리스크 체크리스트**:
- [ ] 대체 기술 리스크: 우회될 수 있는가?
- [ ] 희석 리스크: 대규모 증자/전환사채가 있는가?
- [ ] 지정학 리스크: 민감 지역에 있거나 수출 통제 대상인가?
- [ ] 경영진 리스크: 부정적 이력이 있는가?
- [ ] 고객 집중 리스크: 단일 고객에 과도하게 의존하는가?
- [ ] 밸류에이션 과반영: 현재 밸류에이션이 이미 3년치 성장을 반영했는가?

**병목 지속성 판단**:
- 이 병목은 언제 해소될까?
- 해소된 뒤 이 회사에는 무엇이 남나?
- 일회성인가 지속적인가?
```

## 5단계: 교차 검증 — 한 가지 스토리만 듣지 않는다

### 5.1 정방향 검증

| 검증 항목 | 질문 | 검색 방법 |
|--------|------|---------|
| 고객 검증 | 선두 고객이 이미 계약/도입했는가? | 회사 공시, 고객 실적의 언급 검색 |
| 매출 검증 | 병목이 이미 매출 성장에 반영됐는가? | 최근 2-3개 분기 실적 검색 |
| 가격 검증 | 제품이 가격 인상 중인가? | 업계 호가, 애널리스트 리포트 검색 |
| 생산능력 검증 | 생산능력이 정말 빡빡한가? | 납기 데이터, 고객 불만 검색 |
| 자본 검증 | 증설 자본적지출이 있는가? | 회사 capex 가이던스 검색 |

### 5.2 역방향 검증(멍거식 부정)

| 역방향 질문 | 의미 |
|---------|------|
| 똑똑한 사람들은 왜 이 주식을 사지 않을까? | 알려진 약세 논거 탐색 |
| 이 병목은 우회될 수 있나? 어떤 대체 경로가 있나? | 기술 경로 리스크 |
| 중국/다른 플레이어가 생산능력을 빠르게 복제할 수 있나? | 공급 충격 리스크 |
| 말단 수요가 50% 둔화되면 이 회사는 어떻게 되나? | 하방 민감도 |
| 경영진은 과거 고점에서 증자로 희석한 적이 있나? | 경영진 신뢰도 |
| 현재 밸류에이션은 어떤 성장 가정을 내포하는가? | 밸류에이션 합리성 |

### 5.3 시그널 교차 검증

- 같은 병목의 여러 회사가 모두 오르고 있나?(업계 검증)
- 전방 고객이 실적에서 공급 부족을 언급했나?(고객 검증)
- 업계 협회/연구기관의 관련 데이터가 있나?(제3자 검증)

## 6단계: 출력 — 병목 기회 보드

### 6.1 병목 기회 순위표

| 순위 | 회사 | 코드 | 시가총액 | 연매출 | PS | PE | 병목 고리 | 병목 등급 | 시장 점유율 | 매출 증가율 | 시그널 강도 | 밸류에이션 판단 |
|------|------|------|------|--------|-----|-----|---------|---------|---------|---------|---------|---------|
| 1 | | | | | x | x | | S/A | | | ★1-5 | 합리/다소 높음/과반영 |

**필수 입력 항목**: 시가총액, 연매출, PS, PE는 필수 항목으로, "확인 필요"로 건너뛸 수 없다. 재무 데이터를 확보할 수 없으면 시그널 강도는 ★★를 넘을 수 없다.

시그널 강도 등급(밸류에이션 점검 결과가 등급에 직접 영향):
- ★★★★★ 다중 교차 검증, 고객 도입 완료, 매출 반영 완료, 밸류에이션 청신호(PS 합리적 + 흑자 또는 흑자 임박)
- ★★★★ 대부분 검증 통과, 밸류에이션 청신호 또는 황신호(설명 첨부 필요)
- ★★★ 논리는 성립하나 일부 검증 대기, 밸류에이션 황신호 수용 가능(예: 고성장 초기 기업)
- ★★ 초기 시그널, 또는 병목 논리는 성립하나 밸류에이션 적신호(시가총액>TAM 20%, PS>30x이고 증가율 부족, 시가총액이 5년 전망 크게 초과 등)
- ★ 순수 개념, 미검증

## 매시간 스캔 모드(정기 작업 사용)

매시간 한 번 실행하며, "재료가 있을 때만 보고서를 낸다" 방식을 채택:

### 스캔 흐름(매시간)

1. **뉴스 스캔**: 과거 1-2시간의 공급망 관련 뉴스 검색
   - 키워드: supply chain bottleneck, shortage, capacity constraint, allocation, lead time, sole source, 병목, 품절, 생산능력, 가격 인상
   - 커버리지: 영문 + 중문 소스
2. **시장 시그널**: 추적 중인 회사의 주가 변동 점검(특히 이상 변동 >5% 주목)
3. **실적/공시**: 병목 관련 회사가 실적이나 중대 공시를 발표했는지 점검
4. **밸류에이션 기회**: watchlist 회사가 지수 하락 등의 이유로 매수 구간에 진입했는지 점검
5. **보고서 발행 여부 판단**:
   - 새 병목 시그널, 명확한 종목 기회, 중대한 상태 변화 있음 → **보고서 발행**
   - 새로운 발견 없음 → **보고서 미발행**, 로그에만 "이번 회차 새 시그널 없음" 기록

### 보고서 출력 규칙

**하루에 한 폴더**: `reports/bottleneck-map/YYYY-MM-DD/`

**파일 명명 규칙**(파일 이름만 봐도 종목이 있는지 한눈에 파악):

| 상황 | 파일명 형식 | 예시 |
|------|-----------|------|
| 명확한 종목 발견 | `HH-MM-종목코드1-종목코드2.md` | `09-00-FORM-IBDN.md` |

## AI 리서치 편향 자각

| 편향 | 양상 | 대응 |
|------|-----|------|
| 1등주 선호 | 검색 결과가 대형주에 점령됨 | 의도적으로 소형주 공급사 검색, "small cap" 키워드 추가 |
| 영어 선호 | 일본·한국·대만 회사 누락 | 일본/한국/대만 시장 공급사를 반드시 검색 |
| 서사 선호 | "AI 컨셉" 라벨에 끌림 | 실제 공급망 위치만 보고, 시장 라벨은 보지 않음 |
| 확증 편향 | 병목을 찾은 뒤 긍정 증거만 찾음 | 역방향 검증 강제 실행(5단계) |
| 시의성 편향 | 낡은 정보에 의존 | 최근 30일 데이터 우선 검색 |

## 핵심 원칙(최고 우선순위)

1. **AI에게 종목을 추천하게 하지 말고, 공급망을 분해하게 하라** — 질문이 답보다 중요
2. **물리 우선** — 실제 물리적 제품/소재/장비가 필요한 고리에만 주목
3. **2차, 3차 층** — 이미 충분히 가격에 반영된 1등주는 좇지 않음
4. **교차 검증** — 모든 결론에 최소 2개의 독립 정보원
5. **불확실성을 정직하게 마주하라** — 데이터를 못 찾으면 "데이터 부족"이라 쓰고, 추측으로 채우지 않음
6. **병목에는 시한이 있다** — 모든 병목은 결국 해소되며, 핵심은 시간 창을 판단하는 것
7. **소형주 ≠ 좋은 기회** — 소형주도 형편없는 회사일 수 있으니, 반드시 재무 품질 관문을 통과해야 함
8. **병목이 실재함 ≠ 투자 기회** — 한 회사가 가장 빡빡한 병목에 앉아 있더라도, PS>30x이거나 여전히 적자라면 현재 가격은 매수 시점이 아니다. **밸류에이션은 하드 관문이며, 병목 순도, 시그널 강도, 서사적 매력에 의해 무효화될 수 없다.** 오른 병목주 하나를 놓칠지언정, PS 100배에 적자 회사를 매수하지는 마라
9. **CLAUDE.md 객관성 원칙 준수** — 강세를 미리 정해두지 말고, 데이터 먼저 결론 나중
