# 투자 연구: 버핏-멍거-돤융핑-리루 4대 대가 종합 분석 프레임워크

$ARGUMENTS에 대해 체계적인 투자 연구 분석을 수행한다.

## 연구 프레임워크

버핏, 멍거, 돤융핑, 리루 네 투자 대가의 방법론에 기반하여, 다음 일곱 모듈을 순서대로 실행한다:

### 사전 단계: AI 리서치 편향 자각(반드시 실행)

연구를 시작하기 전에 먼저 해당 회사의 "AI 연구 가능성"을 평가하고, 잠재적 데이터 편향을 식별한다:

**정보 풍부도 등급**:
| 등급 | 특징 | AI 연구 함정 | 대응 전략 |
|------|------|-----------|---------|
| A급(정보 풍부) | 상장한 지 오래, 증권사 커버리지 많음, 미디어 보도 밀집 | 컨센서스가 너무 강해 AI 출력이 시장 가격에 수렴, alpha 제한적 | 반면 검증에 집중: 똑똑한 사람들은 왜 사지 않는가? 간과된 리스크는 무엇인가? |
| B급(정보 보통) | 상장 1-3년, 커버리지 제한적, 일부 데이터는 추산 필요 | AI가 "합리적 추측"으로 공백을 메워, 완전해 보이지만 실제로는 허위 확실성 | 추산 데이터마다 신뢰도 표기, "근거 있는 추산"과 "허공에서 채운 것"을 구분 |
| C급(정보 희소) | 막 상장/비주류 종목/신흥 시장, 커버리지 거의 없음 | AI가 자료 부족으로 과도하게 보수적이 되어, "안 보임=나쁨"으로 오판 | 제1원리 질문 사용(아래 참조), 제한된 정보에서 사업 본질을 추출 |

**C급 회사의 제1원리 연구법**:
공개 자료가 부족할 때, "완전해 보이는" 보고서를 짜맞추려 하지 말고, 다음 기저 질문에 집중한다:
1. 고객은 누구인가? 왜 돈을 내는가? 대체 선택지가 있는가?
2. 재구매는 무엇으로 견인되는가? 습관인가, 락인(lock-in)인가, 아니면 지속적인 새 가치 창출인가?
3. 경쟁사가 100억을 들고 이 사업을 복제할 수 있는가?
4. 경영진은 어떤 핵심 의사결정을 했는가? 그 결정들은 어떤 판단력과 가치관을 반영하는가?

**편향 자체 점검 목록**(연구 전 과정에서 경계 유지):
- [ ] 나의 "확실성" 느낌은 사업 본질에서 오는가, 아니면 자료 수량에서 오는가?
- [ ] 이 회사의 자료량을 절반으로 줄인다면, 내 결론이 바뀔까?
- [ ] AI가 출력한 분석이 시장 컨센서스와 고도로 흡사한가? 그렇다면 나의 정보 우위는 어디에 있는가?
- [ ] "공개 자료는 매우 적지만 사업 본질은 극히 좋은" 가능성이 저평가되고 있지는 않은가?

정보 풍부도 등급 결과를 보고서 서두에 기입하고, 최종 결론에서 "AI 연구 신뢰도"와 "실제 투자 확실성"의 차이를 명시한다.

### 1단계: 데이터 수집

> **데이터 소스 규범**: `skills/financial-data.md` 참조. 모든 재무 데이터는 두 개의 독립 출처에서 와야 하며, 오차 >1%면 표기해야 함.
> - 미국주: macrotrends(주) + stockanalysis(부)
> - 홍콩주: aastocks(주) + macrotrends ADR(부)
> - 중국 A주: 둥팡차이푸(東方財富)(주) + 쥐차오쯔쉰(巨潮資訊)(부)
> - 한국주: KOSPI/KOSDAQ 종목은 `tools/krx_data.py`(quote/valuation/financials/search)로 조회하고 통화는 원(KRW) 기준

Task 도구로 백그라운드 Agent를 실행하여, 웹에서 다음 데이터를 수집한다:

1. 매출 구조: 최근 회계연도 및 최근 4개 분기 부문별 매출, 성장률, 매출총이익률
2. 재무 지표: 최근 5년 매출, 순이익, 매출총이익률, 영업이익률, 잉여현금흐름(FCF), 현금 보유고
3. 경쟁 구도: 시장 점유율, 주요 경쟁사 비교
4. 비즈니스 모델과 해자: 핵심 경쟁우위의 원천
5. 기술 역량: 핵심 기술 스택, 연구개발 투자
6. 경영진: 창업자/CEO 이력, 지분 비율, 핵심 의사결정 기록
7. 산업 전망: TAM(총 도달 가능 시장), 성장 예측
8. 리스크 요인: 지정학, 규제, 공급망 등
9. 현재 밸류에이션: 시총, PE, PS, PEG, EV/Revenue
10. 매수·매도 양측의 핵심 논점

#### 데이터 교차 검증(반드시 실행, 금융 엄밀성 도구 사용)

데이터 수집 완료 후, **반드시 `tools/financial_rigor.py`를 호출하여 핵심 데이터를 프로그램적으로 검증**하고, LLM 암산 오차를 근절한다.

**반드시 검증해야 할 데이터 포인트**:
- 총주식수(거래소, Yahoo Finance, StockAnalysis 등 최소 2개 출처에서 확인)
- 현재 주가와 시총(**주가×총주식수를 수동 계산하여 보고서 시총과 대조, 단위 오류 방지**)
- 최근 회계연도 매출과 순이익(회사 연차보고서 + 최소 1개 제3자 출처에서 확인)
- 현금 보유고와 순현금(현금+단기투자-총부채, 기준 차이 주의)
- 경영진 지분 비율(경제적 권익과 의결권 구분, AB 주식 구조 주의)

**강제 검증 단계(Bash로 도구 호출)**:

Step 1 — 시총 검산(정밀 십진수, 부동소수점 아님):
```bash
python3 ~/ai-berkshire/tools/financial_rigor.py verify-market-cap \
  --price {주가} --shares {총주식수} --reported {보고서 시총} --currency {통화}
```

Step 2 — 핵심 데이터 다중 출처 교차 검증:
```bash
python3 ~/ai-berkshire/tools/financial_rigor.py cross-validate \
  --field {필드명} --values '{"출처1": 수치, "출처2": 수치}' --unit {단위}
```
매출, 순이익, 현금 보유고에 각각 실행한다.

Step 3 — 밸류에이션 지표 정밀 검산(PE/PB/ROE/FCF Yield 등):
```bash
python3 ~/ai-berkshire/tools/financial_rigor.py verify-valuation \
  --price {주가} --eps {EPS} --bvps {주당순자산} --fcf-per-share {주당 FCF} --dividend {주당 배당}
```

**검증 규칙**:
1. 각 핵심 데이터 포인트는 최소 2개 독립 출처
2. 출처 간 차이가 발견되면, 회사 연차보고서/거래소 데이터를 우선 채택하고 차이 원인을 명시
3. **계산이 관련된 모든 데이터는 반드시 도구로 검산, LLM 암산 금지**
4. 도구 출력 결과를 보고서 부록 "핵심 데이터 교차 검증 기록"에 직접 삽입
5. 도구가 ❌ 편차 과대를 보고하면, 반드시 원인을 규명한 후에야 분석 계속 가능

**흔한 오류 예방**:
- 시총 단위: 홍콩달러 억 vs 위안 억 vs 달러 억, 0 하나를 빠뜨리거나 더 쓰기 쉬움
- FCF 기준: 출처마다 자본적지출(CAPEX) 정의가 다를 수 있음(리스, 인수 등 포함 여부)
- 부채 기준: 운용리스 부채 포함 여부
- 지분 비율: AB 주식 회사의 경제적 권익 ≠ 의결권

### 2단계: 사업 본질 분석 — 돤융핑 "옳은 사업"

분석 요점:
- 한 줄로 이 사업의 본질을 정의
- 매출 구조 분해(도표)
- 5년 수익성 추세(도표)
- 비즈니스 모델 캔버스: 일회성 판매 vs 구독/재구매? 하드웨어 vs 소프트웨어 vs 플랫폼?
- 생태계 점착성/고객 락인 강도
- 매출총이익률 수준과 동종업계 비교, 왜 높은지/낮은지 설명
- 영업 레버리지 분석
- **돤융핑식 추궁**: 이 사업은 어디가 좋은가? 한 줄로만 설명해야 한다면, 무엇인가?

### 3단계: 해자 평가 — 버핏 "경제적 해자"

5가지 해자를 하나씩 검증:

| 해자 유형 | 검증 방법 |
|-----------|---------|
| 브랜드/가격결정력 | 판매량 손실 없이 가격을 올릴 수 있는가? |
| 전환비용 | 고객이 경쟁 제품으로 이전하는 비용이 얼마나 높은가? |
| 네트워크 효과 | 사용자가 많을수록 제품이 좋아지는가? |
| 규모의 경제 | 규모가 가져오는 비용 우위가 얼마나 큰가? |
| 기술/특허 장벽 | 기술이 몇 년 앞서는가? 복제 가능한가? |

해자 추세 분석: 지난 5년간 넓어졌나 좁아졌나? 향후 5년 예측.

**버핏식 추궁**: 10년 후에도 이 해자가 남아 있을까? 무엇이 그것을 무너뜨릴 수 있는가?

### 4단계: 역발상과 리스크 목록 — 멍거 "거꾸로 생각하라"

- "이 회사가 실패할 수 있는 모든 경로"를 나열(표: 경로/확률/영향 정도)
- 역사적 유추: 역사상 유사한 위치에 있던 회사를 찾아, 결말이 어땠는지?
- 학제간 분석: 네트워크 효과 이론, 기술 채택 곡선, 경쟁 게임 등 모델로 교차 검증
- 편향 자체 점검: 서사 편향, 앵커링 효과, 생존자 편향
- 매도 측 핵심 논점 수집

**멍거식 추궁**: 나는 어디서 가장 틀리기 쉬운가? 똑똑한 사람들은 왜 이 회사를 안 사거나 공매도하는가?

### 5단계: 경영진 평가 — 돤융핑 "옳은 사람" + 버핏 "경영진 정직성"

- CEO/창업자 핵심 의사결정 복기(표: 시점/결정/결과/점수)
- 자본배분 능력: 연구개발 수익률, 인수합병 성공률, 자사주 매입 타이밍
- 주주 이해 일치성: 경영진 지분, 보수 구조, 지분 매도 기록
- 조직 역량: 팀 안정성, 핵심 인재 리스크
- 기업 문화 특징

**돤융핑식 추궁**: CEO가 은퇴하면, 이 회사는 경쟁력을 유지할 수 있는가?

### 6단계: 산업과 문명 트렌드 — 리루 "문명 진화 프레임워크"

- 속한 산업이 "문명급 패러다임 전환"에 처해 있는지 판단
- 역사적 기술 혁명 유추(증기기관/전기/인터넷/AI)
- TAM 성장 곡선과 천장 분석
- 산업 가치사슬에서 회사의 위치
- 기술 노선 리스크
- 고객/공급업체 집중도 분석

**리루식 추궁**: 20년 후 돌아봤을 때, 이 회사는 "이 시대의 스탠더드 오일"인가, 아니면 "잠깐 피고 진 3Com"인가?

### 7단계: 밸류에이션과 안전마진 — 버핏 "내재가치" + 돤융핑 "옳은 가격"

- 현재 시장 가격(핵심 밸류에이션 지표 표) —— **반드시 도구로 검산**
- 역산 DCF: 현재 주가는 어떤 성장 기대를 함의하는가?
- 3시나리오 밸류에이션 —— **반드시 도구로 정밀 계산, 암산 금지**:
```bash
python3 ~/ai-berkshire/tools/financial_rigor.py three-scenario \
  --price {주가} --eps {EPS} --shares {총주식수 억} \
  --growth {낙관 성장률} {중립 성장률} {비관 성장률} \
  --pe {낙관 PE} {중립 PE} {비관 PE} --years 3 --currency {통화}
```
- 자체 과거 밸류에이션과 비교
- 동종업계 밸류에이션과 비교

**돤융핑식 추궁**: 주식시장이 내일 5년간 문을 닫는다면, 이 가격에 보유할 의향이 있는가?

## 출력 요구사항

1. 모든 분석은 데이터 뒷받침이 있어야 하며, 데이터 출처를 첨부
2. Markdown 표로 핵심 데이터 제시
3. 각 모듈 말미에 반드시 해당 대가의 "추궁"을 둘 것
4. 최종적으로 완전한 보고서를 `~/[회사명]투자연구보고서.md`에 작성
5. 결론은 명확하게, 매수/관망/회피 제안을 회피하지 말 것
6. 밸류에이션 부분은 반드시 구체적인 가격 구간을 제시
7. **보고서 서두**에 반드시 "정보 풍부도 등급"(A/B/C)과 "AI 연구 한계 선언"을 포함
8. **보고서 결말**에 반드시 "AI 분석 신뢰도"와 "투자 확실성"을 구분 —— 전자는 자료량에 좌우되고, 후자는 사업 본질에 좌우됨. 본 보고서의 어떤 결론이 충분한 데이터에 기반하고, 어떤 것이 제한된 정보의 추론에 기반하는지 독자에게 명확히 고지
9. 회사가 C급(정보 희소)에 속하면, 보고서 말미에 반드시 "1차 검증이 필요한 질문 목록"을 나열 —— 독자가 현장 조사, 제품 체험, 공급망 인터뷰 등의 방식으로 AI의 사각지대를 보완하도록 권고

## 데이터 표본 점검(출시 승인 프로세스)

보고서를 파일에 작성한 후, **반드시** 데이터 표본 점검을 실행하고, 통과해야만 발행한다:

**Step 1 — 점검 목록 추출(15% 무작위 표본):**
```bash
python3 ~/ai-berkshire/tools/report_audit.py extract \
  --report <보고서 파일 경로>
```
JSON 템플릿을 출력하며, 각 항목은 `fetched_value`(기입 대기)를 포함한다.

**Step 2 — 수치 취득 검증:**
목록의 각 데이터 포인트에 대해, `skills/financial-data.md` 규범에 따라 신뢰 가능한 정보원에서 수치를 취득
(미국주: macrotrends+stockanalysis; 홍콩주: aastocks+macrotrends; 중국 A주: 둥팡차이푸+쥐차오쯔쉰),
`fetched_value` / `fetched_source` / `fetched_value2` / `fetched_source2`에 기입한다.

**Step 3 — 판정 출력:**
```bash
python3 ~/ai-berkshire/tools/report_audit.py verdict \
  --results '<채워 넣은 JSON>' \
  --report <보고서 파일명>
```

- **【출시 승인】**: 모든 점검 포인트 편차 ≤ 1% → 보고서 발행 가능
- **【반려】**: 임의 포인트 편차 > 1% → 해당 데이터 수정 후 재점검, 출시 승인까지 반복
