# 비상장사 리서치: 멀티 에이전트 병렬 심층 리서치 프레임워크

$ARGUMENTS 에 대한 팀 단위 심층 리서치 분석을 수행한다. 앤트그룹, 샤오훙수, SpaceX, Stripe 등 비상장사를 위해 설계되었다.

**최종 목표**: 정보가 본질적으로 희소한 조건에서 이 회사의 **진짜 가치**를 최대한 복원한다 — 시장이 매긴 밸류에이션이 아니라, 사업 그 자체가 얼마짜리인지를 본다.

## 프레임워크 특징

비상장사 vs 상장사 리서치의 핵심 차이:
- **표준화된 실적이 없음**: 다중 출처를 짜맞추고 교차 검증해야 함
- **밸류에이션 앵커가 적음**: 펀딩 라운드, 비교기업법(Comparable), 시나리오 추정에 의존
- **정보 비대칭이 큼**: 더 많은 "퍼즐 맞추기"식 리서치 방법이 필요
- **엑싯(회수) 경로가 불확실**: IPO/인수합병/세컨더리 매각 모두 가능

## AI 리서치 편향에 대한 자각(본 프레임워크의 핵심 전제)

비상장사는 AI 리서치 편향이 가장 심각한 영역이다. 다음 함정들을 항상 경계해야 한다.

**핵심 모순**: AI는 이미 존재하는 정보를 구조화하는 데 능하지만, 비상장사의 정보는 본질적으로 희소하다. 이로 인해 다음이 발생한다.
1. **가짜 보수성**: 자료가 적다는 이유로 AI가 보수적/모호한 결론을 내리는 경향이 있으나, 자료가 적다 ≠ 회사가 나쁘다
2. **가짜 정밀성**: 리포트 템플릿을 채우기 위해 AI가 "합리적 추정"을 "근거 있는 분석"으로 위장할 수 있음
3. **벤치마킹 함정**: 상장사에 억지로 대조할 때, 상장사의 밸류에이션 논리를 그대로 물려받아 비상장사 고유의 가치를 간과함
4. **생존자 편향**: 인터넷에서 검색되는 회사 정보는 흔히 긍정적으로 편향되어 있음(회사가 자발적으로 퍼뜨리는 것은 대부분 좋은 소식)

**대응 원칙**:
- 추측으로 표를 채워 확실성을 위장하느니, 차라리 "모른다"고 공백으로 두는 편이 낫다
- 모든 데이터 포인트는 신뢰도(🟢높음/🟡중간/🔴낮음)를 표시해 독자가 스스로 판단하게 한다
- "검증 가능한 사실"과 "AI의 추론"을 구분하고, 서로 다른 포맷으로 표시한다
- 정보가 극도로 희소한 회사는 "제1원리 모드"로 전환한다 — 리포트의 완전성을 추구하지 않고, 다음 몇 가지 핵심 질문에만 답한다.
  1. 이 사업은 어떤 진짜 문제를 해결하는가? 수요는 진짜 수요인가, 가짜 수요인가?
  2. 왜 이 팀인가? 그들에게 어떤 고유한 강점이 있는가?
  3. 성공하면 천장은 얼마나 높은가? 실패하면 가장 가능성 높은 사망 원인은 무엇인가?
  4. 현 단계의 핵심 검증 분기점은 무엇인가?

**정보 비대칭의 역이용**: 시장은 비상장사 정보가 적음 → 가격 결정 효율이 낮음 → 바로 이것이 초과수익의 원천이 될 수 있다. AI 리서치의 목표는 정보 비대칭을 없애는 것(불가능)이 아니라, 제한된 정보 속에서 가장 핵심적인 판단 근거를 추출하는 것이다.

## 재무 데이터 짜맞추기(탐정식 리서치)

### 2. 핵심 재무 지표 추산
아래 데이터를 최대한 추산하되, **각 데이터 포인트마다 반드시 표시**: 출처, 시점, 신뢰도, 추산 방법.

**수익 측**:
- 총수익 규모와 성장률(최근 3년, 연간/분기 단위)
- 수익 구조 해부(사업 라인/제품 라인별)
- 수익 성장 동인 분해: 양(유저/거래량) × 가(ARPU/객단가)
- 수익의 계절성 변동 패턴

**비용 측**:
- 매출총이익률 추산(동종 상장사 대조, 선정 논리 설명)
- R&D 비용률 추산(직원 수 × 1인당 급여, 또는 R&D 인력 비중으로 추산)
- 판매비용률 추산(획득 채널과 집행 데이터로 추산)
- 관리비용률 추산

**이익 측**:
- 영업이익/EBITDA 추산
- 순이익/조정 순이익 추산
- 흑자 전환 타임라인: 언제 흑자 전환했는가? 아직 적자라면 예상 시점은?

**현금흐름 측**:
- 영업현금흐름 판단(양/음, 자체 조달 가능 여부)
- 자본적지출(CAPEX) 수준과 추세
- 잉여현금흐름(FCF) 추산
- 보유 현금/번레이트(소진 속도)(펀딩 금액, 펀딩 간격, 직원 수로 추산)
- 캐시 런웨이: 현재 소진 속도로 얼마나 버틸 수 있는가?

**효율 지표**:
- 직원 수와 인당 효율(1인당 수익, 1인당 이익)
- 자본 효율: 1위안 펀딩당 발생하는 수익
- 동종 상장사 효율 지표와 대조

### 4. 펀딩 이력과 밸류에이션 변천
완전한 펀딩 타임라인 정리:

| 라운드 | 시점 | 금액 | 투자 전 밸류 | 투자 후 밸류 | 리드 투자자 | 팔로우 투자자 | 밸류 배수 증가 | 비고 |
|------|------|------|---------|---------|--------|--------|------------|------|

분석:
- 밸류에이션 성장 곡선이 건강한가(라운드별 증가 배수가 합리적인가)
- 펀딩 간격이 합리적인가(지나치게 빈번=소진 빠름? 지나치게 드묾=펀딩 곤란?)
- 밸류에이션 역전(Down Round) 발생 여부
- 기존 주주가 지속적으로 추가 투자하는가(신뢰 신호)
- 최신 라운드의 투자 조건 추정:
  - 우선청산권(1x/2x/participating)
  - 희석방지 보호(full ratchet/weighted average)
  - 베팅 조항(실적/상장 시점)
  - 이들 조항이 보통주 가치에 미치는 영향

### 5. 밸류에이션 분석(다중 방법 교차)

**방법1: 최근 펀딩 밸류에이션법**
- 최근 라운드 밸류에이션 및 시점
- 우선청산권 등 조항을 고려한 "보통주 등가 밸류에이션"(통상 20-40% 할인 필요)
- 현재까지의 시점 차이 조정
- 해당 라운드 투자자의 동기 분석(재무적 투자 vs 전략적 투자, 전략적 투자자는 프리미엄 가능)

**방법2: 비교 상장사법**
- 3-5개 상장 비교기업 선정, 선정 이유 설명
- 핵심 배수 비교:

| 비교기업 | P/S | P/E | EV/EBITDA | EV/Revenue | 성장률 | 이익률 |
|---------|-----|-----|-----------|------------|------|--------|

- 적용 조정:
  - 유동성 할인: 20-30%(구체적 적용값과 이유 표시)
  - 성장 프리미엄/할인
  - 규모 할인
  - 규제/정책 리스크 할인

**방법3: DCF 시나리오 분석**
세 가지 시나리오, 각각 핵심 가정을 나열:

| 가정 | 비관 | 중립 | 낙관 |
|------|------|------|------|

| 종착 상태 영업이익률 | | | |
| 종착 상태 성장률 | | | |
| WACC | | | |
| 종가 배수(EV/EBITDA) | | | |

**방법4: 종착 시총 역산법**
- 5년/10년 후 이 사업이 종착 상태에서 가질 시장 지위를 가정
- 종착 상태 수익과 이익률 가정
- 종착 상태 합리 배수(동종 산업 성숙 기업 참조)
- 현재 합리 밸류에이션 구간 역산
- 내재된 연환산 수익률

**방법5: 거래 대조법**
- 동종 산업 최근 2년의 인수합병/펀딩 거래
- 거래 배수(P/S, P/E)
- 거래 배경과 프리미엄/할인 요인

### 4단계: 6개 병렬 에이전트 시작

Agent 도구로 6개 에이전트를 동시에 시작한다(**반드시 동일한 한 메시지에서 병렬 호출**).

각 에이전트의 설정:
- `subagent_type`: `general-purpose`
- `run_in_background`: `true`

각 에이전트의 prompt 템플릿:

```
당신은 {공사명} 비상장사 리서치 팀의 "{역할 한글명}"이다.

당신은 **비상장사**를 연구하고 있으며, 이는 다음을 의미한다:
- 표준화된 공개 실적이 없으므로 여러 출처에서 정보를 짜맞춰야 함
- 데이터가 불완전하거나 상호 모순될 수 있으므로 신뢰도를 표시해야 함
- 더 많은 추론과 합리적 추산이 필요하나, 추산 과정을 투명하게 보여야 함
- 정보가 검색되지 않음 ≠ 정보가 존재하지 않음, 검색된 정보에 편향이 있을 수 있음

다음 리서치 태스크를 완수하라: {태스크 subject}

구체적 요구사항:
{태스크 description의 내용}

**리서치 방법**:
1. WebSearch 로 최신 공개 정보를 검색, 각 차원마다 최소 3-5회, 다른 키워드 조합으로
2. 검색 키워드 전략:
   - 중국어: 회사명+收入/估值/融资/用户数/MAU/IPO/招股书/裁员/整改
   - 영어: Company Name + revenue/valuation/funding/users/IPO/filing
   - 한국 기업이면: 회사명+매출/밸류에이션/투자유치/이용자수/MAU/IPO/감원
   - 구체적 인명+회사명(경영진 관련 정보 검색)
   - 회사명+구체적 경쟁자명(경쟁 동태 검색)
3. 중점 정보원:
   - 고신뢰도: 투자설명서, 규제 문서, 상장사 연차보고서 내 관계 공시
   - 중신뢰도: 완뎬LatePost, The Information, 36커, Bloomberg, Reuters, TechCrunch
   - 보조 검증: 즈후, 마이마이, Glassdoor, 톈옌차, 치차차
4. WebFetch 로 핵심 기사의 전문을 확보(검색 요약만 보지 말 것)
5. 중요 데이터는 최소 2개 이상의 다른 출처로 교차 검증

**데이터 표시 규범(엄격 준수)**:
- 모든 핵심 데이터에 출처를 표시(미디어명과 기사 제목까지 구체적으로)
- 데이터 시점을 표시(연·월까지 정확하게)
- 신뢰도를 표시: 🟢높음(투자설명서/공식 공시) / 🟡중간(신뢰 미디어/리서치 자료) / 🔴낮음(추산/소문)
- 출처별 데이터가 충돌할 때는 **모두 나열**하고 차이와 당신의 판단을 설명
- "사실"과 "추론"을 구분: 사실은 일반 글꼴, 추론/추산은 *기울임체*로 하고 추산 방법을 표시
- 확보 불가능한 정보는 "데이터 결손"으로 명확히 표시, 날조 금지

**산출 요구사항**:
- 리포트는 상세하게, Markdown 표로 핵심 데이터를 제시
- 각 분석 차원마다 명확한 결론과 평점
- 추산 과정은 완전히 투명하게(계산 논리와 매 단계 가정을 보여줌)
- 리포트 말미에 제공:
  1. 본 차원의 종합 평점(★1-5)과 핵심 판단
  2. 본 차원 정보 완성도 자체 평가(충분/적정/부족/심각하게 부족)
  3. 가장 중요한 3가지 발견
  4. 가장 큰 정보 사각지대(어떤 정보 결손이 판단에 가장 영향을 주는가)
```

### 6단계: 교차 검증과 정보 퍼즐 맞추기

**이것이 강화판 프레임워크에서 가장 핵심적인 신규 단계다**. 취합 전에 team-lead 는 다음을 수행해야 한다.

1. **데이터 충돌 중재**:
   - 각 에이전트 리포트의 핵심 데이터를 추출
   - 서로 다른 에이전트가 인용한 동일 데이터가 일치하는지 식별
   - 충돌 데이터를 중재: 모든 출처를 나열하고, 어느 것을 채택할지, 왜 그런지를 설명

2. **신호 일관성 검사**:
   - 사업 성장 신호(business-decoder) vs 채용 신호(signal-miner)가 일치하는가?
     (사업이 빠르게 성장한다는데 채용이 축소 중이라면 설명이 필요)
   - 기술 선도 서사(tech-ip) vs 특허/인재 데이터(signal-miner)가 이를 뒷받침하는가?
   - 밸류에이션 수준(financial-detective) vs 경쟁 지위(competitive-mapper)가 부합하는가?
   - 경영진 공개 서사(risk-governance) vs 실제 행동 신호(signal-miner)가 일치하는가?

3. **정보 퍼즐 복원**:
   - 6개 리포트의 정보 조각을 짜맞춰, 더 완전한 그림을 복원할 수 있는지 본다
   - 정보의 "백색 구역"(확인된 기지), "회색지대"(단서는 있으나 불확실), "흑색 구역"(완전 미지)을 표시

4. **반편향 점검**:
   - 리포트에 "긍정 정보는 상세, 부정 정보는 간략"한 편향이 있는지 점검
   - 모든 긍정적 판단에 대응하는 반면 검증이 있는지 확인

## 중요 주의사항

1. **6개 에이전트는 반드시 병렬 시작** — 동일한 한 메시지에서 Agent 도구를 6회 호출
2. **데이터 신뢰도 표시** — 비상장사 데이터 출처는 들쭉날쭉하므로, 모든 핵심 데이터에 출처와 신뢰도를 표시해야 함
3. **추산은 투명하게** — 모든 추산 과정은 계산 논리를 보여야 하며, 무에서 숫자를 줄 수 없음
4. **교차 검증** — 핵심 데이터는 최소 2개 출처로 교차 검증, 출처 충돌 시 모두 나열
5. **신호 일관성 검사** — 취합 단계에서 반드시 차원 간 신호 일관성 검사를 수행
6. **결론은 명확하게** — 투자/관망/회피 권고 제시를 회피하지 않되, 동시에 결론의 신뢰도를 밝힘
7. **인내심 있게 대기** — 6개 에이전트 연구에 수 분이 걸리므로, 사용자에게 실시간으로 진행을 갱신
8. **중·영문 검색** — 비상장사 정보는 중국어·영어 미디어에 분산될 수 있으므로 두 언어로 검색 필요
9. **반편향 핵심 원칙** — 자료가 적다 ≠ 회사가 나쁘다, AI 분석 분량이 짧다 ≠ 투자 확실성이 낮다. 정보가 극도로 희소한 회사는 "제1원리 모드"로 전환해 핵심 질문에 집중하고, 리포트 형식의 완전성을 추구하지 않음
10. **정직한 공백** — 리포트에서 "근거 있는 분석"과 "추측성 채움"을 명확히 구분하고, "이 차원은 데이터가 부족해 의미 있는 결론을 낼 수 없음"이 나오는 것을 허용
11. **대체 데이터는 잡음이 아님** — 채용, 특허, 소송, 앱 데이터 등 대체 데이터는 뉴스 보도보다 진짜 경영 상황에 더 가까울 수 있음
12. **진짜 가치 지향** — 최종 목표는 이 사업이 얼마짜리인지 판단하는 것이지, 보기 좋은 리포트를 산출하는 것이 아님. 신뢰할 만한 밸류에이션 판단을 내리기에 정보가 부족하면, 곧바로 "정보 부족, 신뢰할 만한 밸류에이션을 제시할 수 없음"이라고 말할 것

> 한국(KOSPI/KOSDAQ) 종목의 시장 데이터는 `tools/krx_data.py`(네이버금융 기반, quote/valuation/financials/search)로 조회하고, 통화는 원(KRW) 기준이다.
